# Pinball Machine
Pinball machine code for use with arduino

# Components

- DC Power Supply
- Arduino Uno or Mega
- Marble
- 1N4001 Diodes
- LCD
- LEDs
- Piezo-Knock Sensor
- Protoboards
- Push Buttons
- Solenoids
- Resistors (2k,220,1M)
- 74 HC595 Shift Registers
- PN2222A Transistors
- 24 AWG Wire

Tools/Other:
- Wire strippers
- Wire cutters
- Soldering Iron and 60/40 solder
- Saws
- Files
- Plywood
